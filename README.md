# Jumping

Jumping es uno de los proyectos que desarrollé utilizando Unity y C#. La idea del proyecto fue poner en práctica mis conocimientos de desarrollo de videojuegos y experimentar con diferentes mecánicas dentro de Unity.

## Sobre el proyecto

En este proyecto trabajé principalmente en el desarrollo del juego, la programación de las mecánicas y la creación de diferentes elementos dentro de Unity.

Fue un proyecto que me permitió aprender y mejorar en aspectos como la programación en C#, el manejo de escenas, objetos, físicas y la interacción del jugador con el entorno.

## Tecnologías

* Unity
* C#
* Git
* GitHub

## ¿Qué trabajé en este proyecto?

* Movimiento del jugador
* Sistema de salto
* Física e interacción con objetos
* Programación de mecánicas utilizando C#
* Organización de un proyecto de Unity

## Estructura

El repositorio contiene principalmente las carpetas necesarias para abrir y trabajar con el proyecto:

```text
Jumping/
├── Assets/
├── Packages/
├── ProjectSettings/
└── README.md
```

Las carpetas generadas automáticamente por Unity no se incluyen en el repositorio para mantenerlo más limpio y ligero.

## Ejecutar el proyecto

Para abrir el proyecto, descarga o clona el repositorio y ábrelo desde Unity Hub utilizando una versión compatible de Unity.

## Lo que aprendí

Este proyecto fue una oportunidad para seguir mejorando mis conocimientos de Unity, C# y desarrollo de videojuegos, además de aprender a utilizar Git y GitHub para llevar un control de las diferentes versiones del proyecto.
